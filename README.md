# Voz do Mar

é possível desenvolver uma ferramenta que escreva projetos, baseados em aditais publicados?

Vou lhe dar um contexto: Essa ferramenta seria para pescadores artesanais e para as comunidades as quais vivem e devido ao pouco letramento desses comunidades, é muito difícil para eles escreverem um projeto para submissão
